# Changelog

## 1.3.5

- Removed motorcycle-dashboard pairing, authentication, projection, streaming,
  hardware-control, media/call-card, and dashboard-wallpaper implementations.
- Refocused OpenDash on independent app-only route preview, vehicles,
  maintenance, garage, expenses, ride history, themes, and downloadable phone
  wallpapers.
- Replaced obsolete project, privacy, and synchronization documentation.

## 1.3.1

- Added a currency selector in Settings for expense display and exports.
- Improved Android compatibility and redaction in application diagnostics.

## 1.3

- Added a Material 3 interface and theme options.
- Added vehicle-specific garage, maintenance, fuel, and expense records.
- Added editable odometer and mileage calculations.
- Added monthly and all-time expense filtering and sharing.
- Improved ride history, GPS filtering, and general application reliability.
